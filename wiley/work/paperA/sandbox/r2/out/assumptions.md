# Assumptions

- **M2 (hip flexion not in methods list)**: Hip flexion row computed from the dataset's `Hip flexion B/F (kg)` columns, same treatment as the other myometry rows. Why: the table requires it and the data contain it. Rejected: reporting N/A.
- **M3 (FVC sitting vs lying)**: Used the separate `FVC sitting` and `FVC lying` columns (% predicted) as given. Rejected: nothing else plausible.
- **M4 (velocity for participants unable to perform)**: Used the velocities as deposited; the dataset already codes inability as 0 m/s (and 0 m for 6MWT). No recomputation from times. Rejected: excluding non-performers (would contradict the stated purpose of using velocities).
- **M5 (10,000 s in chair-rise medians)**: Chair-rise medians, Wilcoxon test and SRM all use the deposited values including 10,000 s for "unable". Why: the dataset codes inability as 10000 and the median is rank-based, so it is consistent with the ranking rationale; the resulting medians are finite anyway (13/22 able at follow-up). Rejected: dropping non-performers (changes the population and would remove most of the deterioration signal). Note: the SRM for chair rise is therefore dominated by the 10,000 s codes; I report it as computed (0.7388) rather than N/A.
- **M6 / F1 (analysis set)**: Each row uses complete paired cases only (both baseline and follow-up non-missing) for medians, Wilcoxon and SRM. This reproduces the footnoted counts exactly for FVC sitting (17), FVC lying (16), TUG/10-m/stairs (22); myometry and 6MWT rows are complete (23). Rejected: all available values per visit for medians (footnotes about paired counts suggest a paired analysis set).
- **F1 chair rise count discrepancy**: The footnote says 17 paired chair-rise values, but the data have 22 (only participant 20 lacks a baseline). I used n=22 (all paired data). A sensitivity analysis restricting chair rise to the 17 participants with paired FVC sitting is printed in run.log (medB 5.3, medF 9.8, p 0.0016, SRM 0.81). Rejected as primary: no rule in the methods selects those 17.
- **S2 (Wilcoxon variant)**: SPSS default asymptotic test: zero differences discarded, average ranks for ties with tie-corrected variance, no continuity correction, two-sided normal p (scipy `wilcoxon(method="approx", correction=False, zero_method="wilcox")`). Rejected: exact p and continuity-corrected p (exact p is logged as sensitivity).
- **S3 (stars)**: `"a"` when P < 0.05, otherwise `""`. Medians and SRM carry no stars.
- **S4 (SRM direction and SD)**: difference = follow-up minus baseline (the dataset's NOTES define Delta this way), SD with n-1 denominator (SPSS default). So declines are negative and the chair-rise time increase is positive. Rejected: baseline minus follow-up; population SD.
- **Units**: unchanged from the template (%, kg, m, m/s, steps/s, s).
