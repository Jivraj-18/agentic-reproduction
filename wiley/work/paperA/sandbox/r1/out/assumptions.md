# Assumptions

- **M2 (hip flexion not listed in Methods)**: Computed the hip flexion row from the deposited `Hip flexion B/F (kg)` columns exactly like the other myometry rows. Why: data exist and Table 1 reports the row. Rejected: leaving it N/A.
- **M3 (FVC sitting vs lying)**: Used `FVC sitting B/F (%)` and `FVC lying B/F (%)` as separate rows, both already in % predicted. Why: the data have both positions, which matches the table rows. Rejected: reporting only one position.
- **M4 (velocity for participants unable to perform)**: Used the deposited velocity columns as they are. They already hold 0 for participants who could not do the test. Missing baseline values (NaN, participant 20) are left missing. Why: zero is the implied value and is already coded in the data. Rejected: recomputing velocities or treating 0 as missing.
- **M5 / F2 (chair rise 10,000 s in medians)**: Kept the 10,000 s values (unable to perform) in the chair-rise medians as well as in the Wilcoxon test. A median is rank-based, so 10,000 s ranks correctly as "slowest". Result: follow-up median = 7.8 s. Rejected: dropping unable participants from the medians, which would give a different median and sample.
- **M5 / S4 (chair-rise SRM)**: A mean and SD that include 10,000 s are meaningless. So the chair-rise SRM uses only the 13 pairs where both times are real (no 10,000 s). Rejected: SRM including the 10,000 s values (dominated by the placeholder), or reporting N/A.
- **M6 / F1 (analysis set)**: Each row uses complete pairs only, i.e. participants with both baseline and follow-up values, for the medians, the Wilcoxon test and the SRM. Why: this keeps the medians, test and SRM on the same sample, and it matches the footnoted counts for FVC sitting (17), FVC lying (16) and the velocity rows (22). Strength rows and 6MWT are complete (n=23). Rejected: medians from all available values at each visit.
- **M6 / F1 (chair rise n)**: The footnote says 17 paired values for chair rise. The data give 22 pairs once 10,000 s is counted as a valid (ranked) value: only participant 20's baseline is missing. No rule in the methods yields 17 (13 pairs have finite times at both visits), so I used all 22 pairs. Rejected: guessing an exclusion rule to reach 17.
- **S2 (Wilcoxon variant)**: Asymptotic (normal approximation) signed-rank test, matching the SPSS default. Zero differences are dropped (Wilcoxon method), the variance is tie-corrected and there is no continuity correction (`scipy.stats.wilcoxon(method='approx', zero_method='wilcox', correction=False)`). The test is two-sided. Rejected: exact p values; Pratt zero handling; continuity correction.
- **S3**: Marker "a" is set when P < 0.05. Medians and SRM get no marker ("").
- **S4 (SRM direction and SD)**: SRM = mean(follow-up − baseline) / SD(follow-up − baseline), with the n−1 (sample) SD. So a decline in strength or velocity gives a negative SRM, and a slower chair rise gives a positive one. Why: the data NOTES define Delta as follow-up minus baseline, and SPSS uses n−1. Rejected: baseline − follow-up; population SD.
- **Units**: The units are the table units (%, kg, m, m/s, steps/s, s). Nothing was converted.
