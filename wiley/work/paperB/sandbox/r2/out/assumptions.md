# Assumptions and choices (Table 1, CB1-OX1)

- **D1 / F1 – which mock (0.00 µg) columns belong to Table 1 (A1).** The deposited 0.00 µg block has 8 columns, and the same 8 are repeated in the OX1 and OX2 sheets. The OX1-transfected groups have only 4. I read this as two separate mock series, 4 from the OX1 experiments and 4 from the OX2 experiments. Two checks back this up. (i) In cAMP, columns 5-8 have the same full-precision number format as the OX1 groups, and in a Hill=1 per-experiment fit their baseline comes out at exactly 1.0000. That is the same normalisation signature as every OX1 group. Columns 1-4 are 6-decimal values (one is a literal "1"), which matches the OX2 groups. (ii) In βarrestin2, columns 1-4 plateau at about 4-5 fold, like the OX1 groups (4-6 fold). Columns 5-8 reach about 27-30 fold, like the OX2 groups (30-44 fold). **Chosen:** cAMP control = columns 5-8, βarrestin2 control = columns 1-4. *Rejected:* pooling all 8 columns. For βarrestin2 that mixes two populations about 6x apart in Emax, and the 4PL fit breaks down. The pooled result is still printed in run.log as a sensitivity check.
- **M3 – exclusion.** The excluded experiment is not identified, and every deposited column is complete. **Chosen:** no exclusion. I assume the deposited data are already post-exclusion. *Rejected:* guessing which replicate to drop.
- **M4 – normalisation / Emin.** The data are already expressed as fold. The Hill=1 baseline of exactly 1.000 suggests K was the fitted low-concentration plateau. **Chosen:** use the deposited fold values unchanged. *Rejected:* renormalising to the -10 log M point.
- **S2 – how curves are fitted.** The deposited layout is a Prism XY table: 8 replicate sub-columns per group, one column per experiment. **Chosen:** one least-squares fit per transfection group to all individual experiment points, using Prism's equation Y = Bottom + (Top-Bottom)/(1+10^((LogEC50-X)·Hill)) with all parameters free and no weighting (`fit_group_global`). *Rejected:* fitting each experiment and averaging. With only 6 points per curve those fits are unstable (one cAMP control experiment gives logEC50 ≈ -1.7). That version is printed in run.log as a sensitivity check.
- **S6 / S2 – when a 4PL fit "fails", and the sign of the constrained slope (A5).** **Chosen:** a 4PL fit is rejected if any of these hold: it does not converge; logEC50 falls outside [-11, -4] (more than one log unit outside the tested range); SE(logEC50) > 1 log unit; |Hill| is outside [0.1, 10]; or SE(Hill) > |Hill|. A rejected group is refitted with |Hill| fixed to 1. The sign follows the direction of the response: -1 for cAMP inhibition and +1 for βarrestin2. This is the same curve as Prism's "slope = 1" fit with Top below Bottom. The Hill cell then shows ±1.0 and its ± is "N/A". This rule applied to cAMP 0.00 and 0.50 µg and to βarrestin2 0.10 µg. *Rejected:* reporting +1.0 for cAMP. All free cAMP fits have a negative slope, so +1.0 would be inconsistent with them.
- **S5 – potency not estimable.** **Chosen:** apply this rule only if the Hill=1 fit also fails the logEC50 checks. In that case pEC50 = "<5", EC50 = ">10000" nM, and Emax = the mean of the greatest response in each experiment. It was not triggered for Table 1.
- **S3 – Emax definition.** **Chosen:** Emax = the fitted plateau at high CP55,940 concentration, in fold. For cAMP this is the lower plateau, i.e. the residual fold cAMP, e.g. 0.57. *Rejected:* span (1 - plateau) and percent inhibition. pEC50 = -logEC50 (unitless). EC50 in nM = 10^(-pEC50)·1e9, which is the value in parentheses.
- **S4 – meaning of ±.** **Chosen:** the asymptotic standard error of the fitted parameter from the global fit. This matches Prism's default for a pooled XY fit. *Rejected:* SEM across per-experiment fits (shown in run.log).
- **S7 – significance stars.** **Chosen:** one-way ANOVA and Tukey(-Kramer) post hoc on summary data, which is Prism's "mean, SEM, N" entry. Each group is entered as the fitted estimate, its SE treated as the SEM, and N = the number of experiments (4). Stars are given only for each OX1 group compared with 0.00 µg OX1: * p<0.05, ** p<0.01, *** p<0.001. Stars go on the parameter value cell only, and are blank for ± and EC50 cells and for the control row. The Hill slope was not tested because some groups have a fixed Hill with no SE. *Rejected:* ANOVA on per-experiment fitted values. That gives different stars (see run.log) and depends on the unstable per-experiment fits.
- **Units.** The template's units are kept: pEC50 unitless, EC50 in nM, Emax in fold.
