Can an AI rebuild a paper's results table from its Methods and its data alone?

The AI gets only a paper's Methods and the original data the authors deposited, never their code or their results. It rebuilds one results table, and a fixed script grades every number against the published one. Where a number misses, we find out why: usually the Methods left a choice unsaid.

1. Read the MethodsThe Methods are turned into a list of steps, each quoting the paper's own sentence, with the places the paper leaves open marked.
2. Rebuild blindAn AI model works in a closed folder with that list, a blank copy of the table and the authors' data. It writes code, runs it and records every choice it had to make.
3. Grade every cellA fixed script compares each number with the published one: within 2%, within 20%, or further off.
4. Explain the missesA second pass tests each miss against the data and names the cause, and the sentence the Methods would need.
