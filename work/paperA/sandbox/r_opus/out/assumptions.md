# Assumptions

- **M3 (missing / invalid runs)**: Each variable is analysed on its own available runs (complete case per variable, not per run), and every participant stays in the model with whatever runs they have (mixed models handle unbalanced data). Why: this is the standard lme4 behaviour (na.action = na.omit per model). Rejected: listwise deletion of a run if any variable is missing, or dropping participants with incomplete data. Result: time n=502, knot strength n=499, spread n=499, mistakes n=500; 57 subjects each.
- **M3 / S5 (all-zero run)**: Subject 16, technique C, run 1 has knot length before = after = 0, delta knot strength = 0 and spread = 0 (with 2 mistakes). I read this as a failed knot with no loop to measure, and set its knot strength and spread to missing. Time and mistakes are kept. Why: a loop length of 0 is not a physical measurement, and log(0) is undefined, so R's lmer could not have fitted log(delta) with this value in. Rejected: log(x+1) or a small offset for all values, which would change every geometric mean ratio. No other zero or negative delta knot strength values exist.
- **S5 (log base)**: Natural log. Ratios, CIs and p-values do not depend on the base.
- **M4 (time)**: "time total (s)" is stored as "mm:ss" text. It is converted to seconds (minutes*60 + seconds).
- **S2 / S3 / S4 (model structure)**: A fixed effect for technique (reference A) plus run (factor, reference 1), with a random intercept per participant and no technique x run interaction. Why: Table 1 pools all runs, and the methods say the interaction was added only for comparisons within runs. Rejected: including the interaction and averaging over runs, and adding sequence as a fixed or random effect, because the methods do not mention sequence as a predictor. The same structure is used for time, knot strength (both logged), spread and mistakes.
- **S2 / S7 (LMM estimation, CI, p)**: REML (lmer default). Contrasts are estimated-marginal-mean differences (emmeans-style, averaged equally over runs; without the interaction this equals the difference of technique coefficients). CIs and p-values use a t reference with df = n − p − (subjects − 1), about 440. This approximates the Satterthwaite / Kenward-Roger df of a within-subject effect. Rejected: Wald z. With df near 440 the two differ only in the third or fourth significant digit.
- **S6 / S7 (GLMM)**: The outcome is any mistake (≥1) vs none. The model is a random-intercept logistic GLMM fitted by ML with the Laplace approximation (nAGQ = 1, the glmer default), implemented directly as adaptive Gauss-Hermite quadrature with 1 node. Wald z CIs and p-values come from the numerical Hessian (the glmer / emmeans default). Rejected: adaptive quadrature with more nodes, and profile-likelihood CIs.
- **S1 (bracketed means)**: The two bracketed values per row are the model's estimated marginal means for each technique, back-transformed to the response scale. Time and knot strength are therefore geometric means (s, mm), spread is the mean in mm, and mistakes is the predicted probability of at least one mistake per run (inverse logit at the random-effect mode of 0). Why: these are the values emmeans prints next to a ratio, odds ratio or difference, so each row is internally consistent (ratio = m1/m2). Rejected: raw arithmetic means over valid runs, raw geometric means, per-participant means first, and the mean mistake count. The raw arithmetic and geometric means are printed in run.log for reference.
- **S8 (contrast direction)**: "X : Y" is X relative to Y: the ratio X/Y, the difference X − Y, or the odds ratio of X vs Y. A = intracorporeal, B = extracorporeal open, C = extracorporeal closed.
