# Assumptions

- **M2 (hip flexion not in Methods list)**: The workbook has `Hip flexion B/F (kg)` columns, so the hip-flexion row is computed from them exactly like the other myometry rows. Rejected: leaving the row N/A.
- **M3 (FVC sitting vs lying)**: Used the separate `FVC sitting` and `FVC lying` columns (% predicted) for the two rows. Rejected: none needed; the data has both positions.
- **M4 (velocity when unable to perform)**: Used the velocity columns as deposited, where unable = 0 m/s or steps/s. These zeros enter medians, Wilcoxon and SRM. Rejected: dropping participants who were unable, which would defeat the stated purpose of the velocity transform.
- **M5 (chair-rise medians)**: The medians include the 10,000 s placeholder. A median is a rank statistic, so it stays well defined and matches the ranking used in the Wilcoxon test. The 6-year median is (5.8+9.8)/2 = 7.8 s because 9 of the 22 paired participants were unable at follow-up. Rejected: medians over completers only, which would give a much smaller median and hide the loss of function.
- **M5/S4 (chair-rise SRM)**: The source says 10,000 s is "for the purposes of the Wilcoxon" test only, and an SRM built on 10,000 s values would be meaningless. So the chair-rise SRM uses only the 13 pairs where both times were observed. Rejected: SRM with the 10,000 s placeholders.
- **M6 (missing data / analysis set)**: Each row uses the participants with both baseline and follow-up values (complete pairs), and medians are computed on that same paired set. This gives n = 17 (FVC sitting), 16 (FVC lying), 22 (TUG, 10MWR, stairs) and 23 (myometry, 6MWT), which matches the footnotes. Rejected: medians over all available values at each visit.
- **F1 (chair-rise n=17 footnote)**: The data gives 22 chair-rise pairs (only patient 20 lacks a baseline value), not 17. I could not find a rule that gives 17: requiring both times observed gives 13, and dropping only participants unable at both visits gives 21. I used the 22 pairs. Flagged as a possible discrepancy.
- **S2 (Wilcoxon variant)**: I used the SPSS default, the asymptotic (normal-approximation) signed-rank test. It drops zero differences, uses mid-ranks for ties with a tie-corrected variance, applies no continuity correction, and is two-sided. Checked against scipy `wilcoxon(method='approx', correction=False)`, which matches. Rejected: the exact test, which differs for 6MWT and 10MWR. Neither changes significance.
- **S3**: The star marker 'a' is given when P < 0.05.
- **S4 (SRM direction and SD)**: The difference is follow-up minus baseline, matching the workbook's Delta convention, so a decline gives a negative SRM for strength, FVC and velocity rows and a positive SRM for chair-rise time. The SD uses the sample formula (ddof = 1, as in SPSS). Rejected: baseline minus follow-up, and the population SD.
