# Assumptions and choices

- **Data selection (F1)**: I used only the `CB1R - OX1R` block of `crc_cAMP_fold.csv` and the `CB1R-OX1R` block of `crc_barr2_fold.csv`. Each non-empty column is one independent experiment (TASK.md). The 0.00 µg group has 8 columns and the OX1 groups have 4 each. Columns 5-8 of the 0.00 µg group look like mock controls from a second series: they are identical to the 0.00 µg columns in the CB1-OX2 block, and their βarrestin2 Emax is about 28 fold rather than about 4. I kept all 8 because the authors' workbook puts them in the CB1-OX1 block. The alternative I rejected was using only columns 1-4; I had no stated reason to drop data.
- **M3 (exclusion)**: I applied no exclusion. The excluded experiment and condition are not identified. The deposited values are already one value per experiment and concentration, so the technical replicates are already aggregated. The alternative I rejected was guessing an experiment to drop.
- **M4 (normalisation, Emin)**: I used the deposited values as they are, as fold. They already appear normalised (the cAMP values are about 1 at 0.1 nM, and some are exactly 1). I did not renormalise. The alternative I rejected was dividing again by the lowest-concentration mean, which would double-normalise.
- **S2 (fitting scheme)**: My main analysis fits one curve per transfection group. Each independent-experiment value goes in as its own point, which matches Prism's default for replicate Y columns. The model is the Prism "log(agonist) vs. response, variable slope" 4PL, fitted by unweighted least squares (scipy `curve_fit`), with Prism-like starting values (Bottom = min Y, Top = max Y). The alternative was to fit each experiment separately and average. Those individual 6-point fits were very unstable (cAMP pEC50 ranged from 6.6 to 10.3 within one group). I print that analysis in `run.log` as a sensitivity check, but it is not used in the table.
- **S2/S6 (when a 4PL fit "failed")**: I counted a fit as failed if any of these held: it did not converge, the covariance was not finite, logEC50 fell outside [-11, -4] (the tested range plus one log unit), the slope had the wrong sign for the assay direction, |Hill| fell outside [0.2, 5], SE(Hill) > |Hill|, or SE(logEC50) > 1. In that case I refit with |Hill| fixed at 1, with the sign following the curve direction so that a fall is allowed for cAMP. The table then reports Hill = 1 with "N/A" for its ±. The alternative I rejected was reporting -1 for cAMP. The paper says "constrained to 1", and Prism's 3-parameter model fixes the slope at +1 and swaps Top and Bottom for a falling curve. Groups constrained: cAMP 0.00 and 0.50 µg; βarrestin2 0.00 and 0.10 µg.
- **S3 (Emax definition)**: For cAMP inhibition, Emax is the fitted lower plateau in fold (the maximal inhibition, below 1). For βarrestin2, it is the fitted upper plateau. I rejected using the span (top minus bottom), because the column is labelled "Emax (Fold)" and fold values are plateau levels. EC50 (nM) = 10^logEC50 × 1e9. The pEC50 column is unitless. The free cAMP Hill slopes keep their sign, which is negative for a falling curve, as Prism reports them.
- **S4 (±)**: The ± is the standard error of the fitted parameter from the pooled fit, which is what Prism reports alongside a best-fit value. I rejected the SEM across experiments because it only exists under the per-experiment scheme I did not use as the main analysis (see the sensitivity output in `run.log`).
- **S5 (potency not estimable)**: I implemented this rule: if logEC50 falls outside [-11, -4] even with the slope constrained, pEC50 is "n.d.", EC50 is ">10000" nM and Emax is the greatest observed response. The rule never triggered.
- **S7 (stars)**: I ran a one-way ANOVA followed by Tukey-Kramer from summary data: the best-fit value as the mean, SD = SE × √n, and n = number of independent experiments (8 or 4). Prism does the same when data are entered as mean, SEM and n. Each OX1 group is compared with 0.00 µg, which I take as the reference because the legend's "relative to CP55,940" most plausibly means CP55,940 in mock cells. Stars are * p<0.05, ** p<0.01 and *** p<0.001. The 0.00 µg row never gets stars, and an empty string means not significant. Hill slopes were not compared, because the reference group's slope was constrained. The alternative was ANOVA on per-experiment fitted parameters; its p-values are printed in `run.log` as the sensitivity analysis.
