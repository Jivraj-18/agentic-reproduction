# Assumptions (Table 1, CB1-OX1)

- **Data block (F1)**: used the `CB1R - OX1R` block of `crc_cAMP_fold.csv` and the `CB1R-OX1R` block of `crc_barr2_fold.csv`. Each non-empty column under a condition header is treated as one independent experiment (value = that experiment's mean of its technical triplicate).
- **M2b (n=4-8)**: the deposited workbook lists 8 experiment columns under "0.00 µg OX1R" and 4 under each OX1 amount. I used all 8 for the 0.00 µg control, because the deposit groups them under that header and the paper says n=4-8. Rejected: using only the first 4 columns (they look like the OX1 series, and columns 5-8 look like the OX2 series' control). That alternative changes the 0.00 row a lot (βarr2 observed Emax about 4.37 instead of 16.54; cAMP pEC50 8.99 instead of 8.83). `run.log` prints it as a sensitivity check.
- **M3 (exclusion)**: there are no blank cells in the CB1-OX1 blocks, so I excluded nothing. I assumed any excluded replicates were already removed before the per-experiment values were deposited. Rejected: guessing which experiment to drop.
- **M4 (normalisation)**: the data are already expressed as fold, so I did not renormalise. Rejected: dividing again by the lowest-concentration mean, which would double-normalise.
- **S2 (fit strategy)**: fitted one variable-slope 4-parameter log(agonist)-response curve per condition, by least squares, to all per-experiment points pooled. This is how Prism fits a grouped table with replicates. I tried several starting values for logEC50 and kept the fit with the lowest RSS. Rejected: fitting each experiment separately and averaging, because the paper talks about "the CRC" for a condition failing to fit or not reaching an asymptote, which implies one curve per condition. Six points per experiment also make per-experiment 4PL fits unstable.
- **S2/S6 (when the 4PL fails)**: I followed F2 and constrained the Hill slope only for the cAMP 0.50 µg curve. The data back this up: that unconstrained fit gives Hill = -12 and a singular covariance (infinite SEs), while all other curves give finite SEs.
- **S6 (sign of the constrained slope)**: for the downward cAMP curve I fitted nH = -1, which is the same as Prism's 3-parameter model with slope 1 and Top below Bottom. I report the Hill value as 1.0, the "constrained to 1" in the text, with ± = "N/A". Rejected: printing -1. The fitted curve is identical either way; only the printed sign differs.
- **S3 (Emax)**: for cAMP inhibition, Emax = the fitted plateau at high agonist concentration (the bottom plateau, in fold below 1). For βarrestin2, Emax = the top plateau. Rejected: the span (1 - bottom).
- **S3 (pEC50 / EC50)**: pEC50 = -logEC50 (M). EC50 in nM = 10^(-pEC50) × 1e9. The cAMP Hill slopes are reported negative (descending curve, Prism agonist model).
- **S4 (±)**: ± is the asymptotic standard error of the best-fit parameter from the pooled fit. Rejected: SEM across per-experiment fits (see S2). The exception is the observed βarr2 0.00 µg Emax, where ± is the SEM across experiments.
- **F3/S5 (βarr2 0.00 µg, "observed" Emax)**: Emax = mean ± SEM across experiments of the response at the highest concentration (10 µM). For the EC50 bound I report pEC50 "<5.5957" and EC50 ">2537 nM", using the unconstrained 4PL estimate as the bound, because the curve is still rising at 10 µM. I still report the Hill slope from the unconstrained fit, which is poorly determined. Rejected: using ">10 µM" as the bound, because the fitted midpoint lies inside the tested range.
- **S7 (stars)**: one-way ANOVA plus Tukey-Kramer, computed from summary statistics (best-fit value, SE treated as SEM, n = number of experiments), the way Prism does ANOVA from mean/SEM/N. Each OX1 group is compared with 0.00 µg. A star is given only if the ANOVA p < 0.05 and the Tukey p < 0.05 (*), < 0.01 (**) or < 0.001 (***). Tests are skipped where the reference value is a bound (βarr2 pEC50 and Hill), and the constrained Hill is left out of the tests. Rejected: ANOVA on per-experiment fitted parameters (not available under the pooled-fit choice).
