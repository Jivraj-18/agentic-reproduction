# Assumptions (Table 1, CB1-OX1, CP55,940)

- **Data blocks (F1)**: I used the "CB1R - OX1R" block of `crc_cAMP_fold.csv` and the "CB1R-OX1R" block of `crc_barr2_fold.csv`. Each non-empty column is one independent experiment (already the mean of its technical triplicate); x = log10[CP55,940] (M), -10 to -5. I ignored the CB1-OX2 and CB2 blocks (and the CB2 header labels that look swapped).
- **M2b (n = 4-8)**: I used every non-empty column. The 0.00 µg (mock) groups have 8 columns in both assays and the OX1 groups have 4, so I read n = 8 for the controls and n = 4 for the transfected groups. In the barr2 0.00 µg group, experiments 5-8 reach about 30-fold while experiments 1-4 reach about 4-5-fold. I kept all 8 anyway. Rejected: dropping columns 5-8, because nothing in the methods says to.
- **M3 (exclusion)**: No cells are blank inside the CB1-OX1 blocks, and the deposit is already per-experiment fold data. I assumed the excluded triplicate was removed before export, so I excluded nothing more. Rejected: guessing an outlier experiment to drop.
- **M4 (normalisation, Emin)**: The deposited values are already "fold" (Y/K). I used them as they are and did not normalise again. Rejected: renormalising each column to its -10 M value, because that would apply K twice.
- **S2 (fit strategy)**: I fit one curve per condition to all points pooled across experiments (Prism's default for replicate Y columns), by unweighted least squares with the Prism 4PL equation `Y = Bottom + (Top-Bottom)/(1+10^((LogEC50-X)*Hill))`. I constrained the Hill sign to the direction of the response: negative for cAMP inhibition, positive for barr2 recruitment. Rejected: fitting each experiment and averaging. That version is printed in run.log as a sensitivity check; the per-experiment cAMP fits are unstable (one 0.00 µg experiment gives pEC50 > 20).
- **S2/S6/F2 (when to constrain)**: Footnote a decides this, so only the 0.50 µg cAMP curve uses the Hill = 1 fit. That curve's unconstrained fit is degenerate (SE of LogEC50 is about 2000). The script logs an objective "failed" flag (logEC50 outside the tested range, SE(logEC50) > 1, or SE(Hill) > |Hill|). The flag also fires for the cAMP 0.00 µg curve (Hill -1.70 ± 3.59), but I kept that curve at 4PL as F2 says. Rejected: letting the flag override the footnote.
- **S6 (sign of "constrained to 1")**: I used Prism's "log(agonist) vs. response" equation with Hill = +1. For a downward curve this fits Top < Bottom, so I report the Hill slope as 1.0, with "N/A" for its ± because a fixed parameter has no SE. Rejected: reporting -1 (the same curve with the sign flipped).
- **S3 (Emax for cAMP)**: Emax is the fitted lower plateau, i.e. the fold of forskolin cAMP left at maximal inhibition (for example 0.79 for mock). For barr2, Emax is the fitted upper plateau. Rejected: the span (Top - Bottom).
- **S3 (units)**: pEC50 is -log10 EC50 (M) and has no unit. EC50 is given in nM as 10^(-pEC50) x 1e9.
- **S4 (±)**: The ± is the asymptotic standard error of the pooled-fit parameter (Prism's "Std. Error"). Rejected: SEM across per-experiment fits (see the sensitivity block in run.log).
- **F3/S5 (barr2 0.00 µg)**: The observed Emax is the mean ± SEM across the 8 experiments at the highest concentration (10 µM): 16.54 ± 4.62. The EC50 is given as a bound because the curve has no asymptote inside the tested range: pEC50 "<5", EC50 ">10000" nM. The pEC50 ± is "N/A". For the Hill slope I report the pooled 4PL estimate, since the methods give no special rule for it. Rejected: the maximum single response, and reporting the unstable fitted pEC50 (5.60 ± 1.37).
- **S7 (stars)**: One-way ANOVA then Tukey's test, run from summary statistics. Each group enters as its table value, ± SE taken as the SEM, and n = number of experiments, as Prism does for a "Mean, SEM, N" table. Only comparisons against 0.00 µg get stars (* p<0.05, ** p<0.01, *** p<0.001). A parameter gets no stars when the reference value is a bound (barr2 pEC50). A row whose value is constrained, with no SE, is left out of that ANOVA (cAMP Hill at 0.50 µg). Rejected: ANOVA on per-experiment fitted parameters, which run.log reports: it gives no significant cAMP Emax differences.
- **Template column "camp_ec50"/"arr_ec50"**: This is the EC50 in nM shown in parentheses in the table, computed from pEC50.
